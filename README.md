# Раскраска

Раскраска по номерам на известных картинах (`b8k-paint`), сделанная для
пожилого человека: крупные клетки и кнопки, без таймера, очков и рекламы.

- Картина разбита на клетки с номерами, внизу палитра крупных кнопок. Выбрал
  цвет, нажал на клетку — закрашивается вся связная область этого номера.
- Справа кнопки: крупнее, мельче, вся картина, «где?» (ближайшая незакрашенная
  клетка выбранного цвета), отмена, «посмотреть» готовую картину.
- Прогресс сохраняется после каждого нажатия в `~/.local/share/b8k-paint/`.
- 37 встроенных картин в общественном достоянии (Айвазовский, Шишкин,
  Левитан, Куинджи, Хокусай, Ван Гог и другие) от 64 до 128 клеток;
  `make-paintings.py` делает их из файлов Wikimedia Commons.
- Свои фотографии: JPEG или PNG в папке `~/Раскраски`.
- «+ Найти»: поиск картин в Wikidata по художнику, названию или сюжету (и
  по-русски), картинки с Wikimedia Commons; предпросмотр раскраски в четырёх
  размерах клеток (64, 96, 128, 160) и загрузка выбранных в галерею.

## Установка

Нужны Python 3, GTK 3, PyGObject, pycairo и Pillow. В Alpine:

```
apk add python3 py3-gobject3 gtk+3.0 py3-cairo py3-pillow
```

Поставить в систему (нужен root):

```
sh install.sh            # в /
sh install.sh /mnt/root  # в другой корень, например при сборке образа
```

`install.sh` кладёт программу в `/usr/local/bin/b8k-paint`, картины в
`/usr/local/share/b8k/paint/`, значок и раздел для
панели оболочки в `/usr/local/share/b8k/apps.d/paint.conf`.

## Оболочка планшета

Программа сделана для оболочки
[lenovo-b8000h-linux](https://github.com/trudenboy/lenovo-b8000h-linux)
(Linux на Lenovo YOGA Tablet 10 B8000-H), её сборка ставит программу
отсюда по тегу. Если в системе есть модуль оболочки
`/usr/local/share/b8k/python/b8k_ui.py`, программа берёт из него вибрацию на
нажатия, общий вид заголовка и вопрос «Стереть?» в стиле
оболочки. Без него она работает на любом рабочем
столе с GTK 3.
